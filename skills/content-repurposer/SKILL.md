# Content Repurposer

One idea, six channels, each written for how that channel actually talks.

## Inputs

- The original content
- Brand name, one-liner and voice notes (or a voice file to read)
- Which of the six formats are needed

## Formats

1. X thread: 7 to 10 posts, the hook in post one, one idea per post
2. Telegram: short and punchy, link at the bottom
3. LinkedIn: professional framing, same core idea, no hashtag walls
4. Instagram caption: hook, three points, call to action
5. Discord announcement: insider tone, written for people already in the community
6. Email intro: two direct paragraphs

## Rules

Never paste the same copy across channels. Each version should be able to stand alone, and each should keep the original's single strongest claim.

## Output

Six clearly labelled sections, plus a note on which version to post first and why.
